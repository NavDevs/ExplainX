How to Install

  1. Download the source `.zip` file.
  2. Extract the downloaded folder.
  3. Open chrome://extensions/ in Chrome.
  4. Toggle Developer mode in the top right.
  5. Click Load unpacked and select the extracted folder.

How to Use

  • Select any confusing text on a webpage.
  • Click the floating ExplainX toggle button, or press Cmd+Shift+E.
  • Read the AI's instant explanation.
  • Chat with the AI to ask follow-up questions or use slash commands.
