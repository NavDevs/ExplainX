🚀 Installation & Deployment (Windows & macOS)

ExplainX is a Chrome extension, meaning it runs seamlessly across both Windows and macOS systems without any OS-specific configuration!

  1. Download the Release: Go to the GitHub Releases page and download the latest .zip file.
  2. Extract the ZIP:
    • Windows: Right-click and select "Extract All..."
    • macOS: Double-click the zip file to extract.
  3. Open Extensions: Navigate to chrome://extensions in Google Chrome.
  4. Enable Developer Mode: Toggle the switch in the top right corner.
  5. Load Extension: Click "Load unpacked" and select the extracted folder.
